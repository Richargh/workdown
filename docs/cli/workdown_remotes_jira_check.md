## workdown remotes jira check

Verify Jira connectivity and PAT validity

```
workdown remotes jira check [flags]
```

### Options

```
  -h, --help             help for check
      --pat string       Jira personal access token
      --project string   Jira project key to validate
      --url string       Jira base URL
```
