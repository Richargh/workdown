## workdown remotes jira pull

Pull selected Jira issues as Workdown interchange

```
workdown remotes jira pull [flags]
```

### Options

```
      --format string    Output format (default "json")
  -h, --help             help for pull
      --issues string    Comma-separated Jira issue keys to pull
      --limit int        Maximum number of Jira issues to pull
      --mine             Pull issues assigned to the authenticated user
      --pat string       Jira personal access token
      --project string   Jira project key
      --url string       Jira base URL
```
