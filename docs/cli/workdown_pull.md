## workdown pull

Pull work items to Markdown

```
workdown pull [flags]
```

### Options

```
  -h, --help             help for pull
      --issues string    Comma-separated issue keys to pull
      --limit int        Maximum number of issues to pull
      --mine             Pull issues assigned to the authenticated user
      --out string       Output directory (default "items")
      --pat string       Personal access token
      --project string   Project key
      --remote string    Remote provider name (default "jira")
      --url string       Remote base URL
```
