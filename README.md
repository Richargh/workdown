# Workdown

Workdown is a CLI for syncing issue tracker work items with local Markdown files. 

Has plugins to support:

* Jira

## Usage

```bash
# show help
go run ./cmd/workdown -h

# list plugins
go run ./cmd/workdown plugins
```
